# 🎮 ZenoxGD Launcher

**A custom Geometry Dash launcher with a sleek dark/neon UI**  
*Created by SONI*

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎮 **Play GD** | Launches Geometry Dash from your Steam install path |
| 🎨 **Texture Packs** | Open the Geometry Dash textures folder to manage custom packs |
| 🔧 **ZenoxRepair** | SONI's custom repair tool — checks game health, clears cache, resets preferences |
| 👤 **GD Account** | Opens the official Geometry Dash account page |
| 💾 **Auto-Save Config** | All settings persist to `%APPDATA%\ZenoxGD\config.json` |
| 🌙 **Dark/Neon Theme** | Purple `#b14aed` · Red `#ff2255` · Green `#00ff88` · Cyan `#00e5ff` on `#0a0a14` bg |

## 🚀 Quick Start (Development)

### 1. Clone & Install
```bash
git clone https://github.com/soni/zenoxgd-launcher.git
cd zenoxgd-launcher
pip install -r requirements.txt
```

### 2. Run
```bash
python main.py
```

The launcher will open with the dark neon theme. Click **Play GD** to launch the game!

## 🔨 Building the .exe

### Option A: Using build.bat (Recommended)
```cmd
build.bat
```
This will:
- Create a Python virtual environment
- Install all dependencies
- Run PyInstaller in `--onefile` mode
- Output: `dist/ZenoxGD Launcher.exe`

### Option B: Manual PyInstaller
```cmd
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name "ZenoxGD Launcher" --add-data "assets;assets" main.py
```

### Option C: Using the .spec file
```cmd
pip install pyinstaller
pyinstaller ZenoxGD_Launcher.spec
```

## 📀 Creating the Windows Installer

### Prerequisites
- [Inno Setup 6](https://jrsoftware.org/isdl.php) installed
- Build the `.exe` first (see above)

### Steps
1. Open `ZenoxGD_Installer.iss` in **Inno Setup Compiler**
2. Press **Ctrl+F9** (or Build → Compile)
3. The installer will be generated at:
   ```
   Output/ZenoxGD_Launcher_Setup_v1.0.0.exe
   ```

### What the Installer Does
- ✅ Installs to `Program Files\ZenoxGD Launcher`
- ✅ Creates Start Menu shortcuts (launch + uninstall)
- ✅ Optional Desktop shortcut
- ✅ Optional Quick Launch shortcut  
- ✅ Optional run at Windows startup
- ✅ Offers to launch the app after installation
- ✅ Auto-uninstalls previous version on upgrade
- ✅ Full cleanup on uninstall (including `%APPDATA%\ZenoxGD`)
- ✅ English & Spanish language support

## ⚙️ Configuration

Settings are stored in:
```
%APPDATA%\ZenoxGD\config.json
```

| Key | Default | Description |
|---|---|---|
| `gd_path` | `C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash` | Path to GD install |
| `auto_start` | `false` | Auto-launch GD on launcher start |
| `close_on_play` | `true` | Close launcher after clicking Play |
| `theme_mode` | `dark` | CTk theme (dark/system/light) |
| `accent_color` | `purple` | CTk accent color |

## 🔧 ZenoxRepair

SONI's custom repair tool built into the launcher. Features:
- **Health Check**: Verifies GD executable exists and is valid
- **Clear Cache**: Removes `C:\Users\<You>\AppData\Local\GeometryDash` cache files
- **Reset Preferences**: Deletes GD's `userdata` folder to reset settings
- **Custom GD Path**: Browse and select a different GD installation folder
- **Progress Bar**: Visual feedback during repair operations
