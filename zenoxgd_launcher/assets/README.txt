ZENOX GD LAUNCHER - Assets Directory
=====================================
Created by SONI

Place your launcher icon here as  icon.ico

Requirements:
  - Format:  .ico
  - Recommended sizes: 16x16, 32x32, 48x48, 64x64, 128x128, 256x256
  - Can be created from a .png using online converters or ImageMagick:
      convert icon.png -define icon:auto-resize=256,128,64,48,32,16 icon.ico

Optional wizard images for Inno Setup:
  - wizard_small.bmp  : 164 x 314 pixels  (left panel of setup wizard)
  - wizard_large.bmp  : 150 x 50  pixels  (top banner of setup wizard)

NOTE: The launcher will still work without icon.ico - it will use
the default CustomTkinter window icon instead.
